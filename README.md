# 🤖 Bot de Ticket para Discord

Este é um projeto pronto para um bot de suporte por tickets no Discord utilizando **Discord.js v14**.

## 🛠️ Instalação e Uso

1. Extrai os arquivos deste repositório/ZIP.
2. Instale as dependências executando:
   ```bash
   npm install
   ```
3. Renomeie o arquivo `.env.example` para `.env` e preencha com o seu token e IDs correspondentes.
4. Inicie o bot:
   ```bash
   npm start
   ```
5. No Discord, use o comando `!setup-ticket` no canal onde deseja exibir o painel.
